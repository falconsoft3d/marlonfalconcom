# Odoo SIS20

Odoo SIS20 es una vertical de salud para la implementación de un ERP en clínicas y hospitales. Odoo SIS20 fue desarrollado por Marlon Falcón Hernández.

Una vertical es un conjunto de módulos que adapta un ERP generalista, como Odoo, a las necesidades de un sector concreto. En este caso, SIS20 añade a Odoo los procesos propios de un centro de salud, de forma que la gestión clínica y la administrativa (facturación, contabilidad, etc.) conviven en un mismo sistema.

# Características de Odoo SIS20
- Gestión de citas médicas.
- Gestión de pacientes.
- Gestión de médicos.
- Gestión de locales médicos.
- Gestión de especialidades médicas.
- Gestión de facturación.
- Ficha clínica del paciente.
