# ▷ Cómo crear un APU
import Image from 'next/image'


El **APU** (siglas de **A**nálisis de **P**recios **U**nitarios) es el desglose del coste de una actividad o partida de un proyecto u obra en construcción. En él se agrupan los recursos necesarios para ejecutar una unidad de esa actividad: **materiales, mano de obra, equipos y valores porcentuales**. Sumando el coste de cada recurso según su cantidad o rendimiento se obtiene el precio unitario de la partida, que después se multiplica por la cantidad medida para obtener el presupuesto.
