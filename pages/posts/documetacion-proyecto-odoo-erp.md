# ▷ Documentación de proyecto en Odoo ERP
Cuando iniciamos un proyecto de implantación de Odoo es necesario cargar la información de los usuarios, clientes, proveedores, productos, etc. Recopilar estos datos de forma ordenada desde el principio ahorra mucho tiempo y evita errores en la importación. En este post comparto las plantillas que utilizo para recoger esa información.


## D01 - Matriz de usuarios
En este documento se detalla la matriz de usuarios del proyecto. Cada celda debe rellenarse con 0 o 1 según si el usuario tiene acceso o no a cada una de las aplicaciones.

* D01 - Matriz de usuarios [Descargar xlsx](/templates/d01-matriz-usuarios.xlsx)


## D02 - Plantilla de productos
En este documento se detallan las columnas que se deben rellenar para cargar los productos en Odoo.

* D02 - Productos [Descargar xlsx](/templates/d02-productos.xlsx)

Una vez completadas, estas plantillas sirven como base para importar los datos en Odoo con la herramienta de importación de Excel/CSV que incluyen sus vistas de lista.
