# MC - Midnight Commander
Midnight Commander es un administrador de archivos para la terminal. Es muy útil para navegar por los archivos y carpetas de nuestro sistema operativo, y para mover, copiar, renombrar, eliminar o crear archivos y carpetas, sobre todo cuando trabajamos en un servidor sin entorno gráfico.

# Instalación

```bash
sudo apt install mc
```

Una vez instalado, se abre escribiendo `mc` en la terminal. La interfaz muestra dos paneles, uno junto al otro, y las acciones principales están asignadas a las teclas de función (F5 copiar, F6 mover, F7 crear carpeta, F8 eliminar, F10 salir).
