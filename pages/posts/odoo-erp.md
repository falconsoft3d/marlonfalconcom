# Odoo ERP
Odoo ERP es un software libre que puede ser instalado en la nube y que cuenta con una app para que puedas interactuar con él desde tu celular. Tiene varios módulos muy interesantes para la administración de las empresas.

Anteriormente se conocía como OpenERP. Es un sistema ERP integrado de código abierto desarrollado actualmente por la empresa belga Odoo S.A. El fabricante declara su producto como una alternativa de código abierto a SAP ERP y Microsoft Dynamics.

# Principales ventajas de Odoo ERP
1. Es un ERP que se puede instalar en la nube.
2. Es de código abierto.
3. Es fácil de parametrizar.
4. Consume pocos recursos.
5. Se puede abrir desde el celular.
6. Gestiona diferentes procesos.
7. Se puede integrar con otros sistemas.

# CRM (Customer Relationship Management)
Si necesitas gestionar las relaciones de ventas con los clientes, Odoo ERP te facilita el trabajo con el módulo CRM, que te permite descubrir oportunidades, controlar en qué etapa se encuentra cada venta y conocer el trabajo de los vendedores.

# Módulo de Compras
El módulo de compras gestiona todo el proceso de compra de la empresa, desde el presupuesto hasta la entrada de mercancía al inventario. Se puede comprar con diferentes monedas.

# Módulo de Contabilidad
El módulo de contabilidad lleva el control del libro mayor, cuentas contables, gastos, asientos contables, los activos, diferentes tipos de monedas y los informes contables. También se puede implementar con módulos desarrollados a medida la facturación electrónica con SII en Chile.

# Módulo de Inventario
El módulo de Inventario de Odoo gestiona fácilmente los almacenes, las ubicaciones y los controles de inventario y, con reportes muy dinámicos, permite exportar a Excel los resultados para poder tomar decisiones.

# Módulo de TPV o punto de venta
El módulo de punto de venta (POS) permite trabajar con código de barras, balanza electrónica, diferentes formas de pago e impresoras térmicas. Una de sus principales ventajas es que puede trabajar sin conexión (offline) y, cuando la señal se restablece, sincroniza todos los pedidos.
