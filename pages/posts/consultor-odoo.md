# Consultor Odoo ERP

Un consultor de Odoo ERP es un profesional con conocimientos funcionales y técnicos de Odoo que ayuda a una empresa a implementar el sistema: analiza sus procesos, configura los módulos necesarios, adapta o desarrolla lo que el estándar no cubre y forma a los usuarios para que puedan trabajar con él.

## Ventajas de contratar un consultor Odoo ERP

Para una empresa es ventajoso contratar un consultor de Odoo ERP porque:

1. Conoce a fondo Odoo y sabe qué puede resolver el estándar y qué requiere desarrollo, lo que evita trabajo innecesario.
2. Puede guiar a la empresa durante la implementación, desde el análisis de procesos hasta la puesta en marcha.
3. Puede personalizar Odoo para adaptarlo a las necesidades concretas de la empresa.
4. Reduce los errores habituales de configuración, migración de datos y formación de usuarios.

## Tipos de consultor Odoo ERP

1. **Consultor Odoo ERP independiente**: un profesional autónomo, normalmente con trato directo y más flexibilidad.
2. **Empresa de consultoría Odoo ERP**: un equipo con varios perfiles (funcionales, desarrolladores, soporte), adecuado para proyectos de mayor tamaño.

## Conocimientos de un consultor Odoo ERP

Un consultor Odoo ERP debería dominar al menos 20 de estos conocimientos:

1. Heredar modelos y vistas / agregar campos.
2. Heredar modelos y vistas / reemplazar campos.
3. Heredar modelos / reemplazar funciones.
4. Cargar datos.
5. Crear permisos.
6. Crear reglas de dominio.
7. Crear campos calculados (store True/False).
8. Secuencias.
9. Controladores web.
10. Reportes PDF.
11. Reportes XLS.
12. Dashboards.
13. Cargar datos por RPC.
14. Aspectos funcionales de Odoo.
15. Crear pedidos, facturas y albaranes.
16. Wizards (asistentes).
17. Acciones.
18. Traducciones.
19. Tareas programadas (cron).
20. Enviar emails.
21. Notificar a usuarios.
22. Trabajar con campos many2many.
23. Agregar botones inteligentes (contadores) en la parte derecha de los formularios.
24. Trabajar con estados y bloquear campos según el estado.
25. Manejar errores (raise / try).
26. Trabajar con Jinja2.
27. Web scraping.
28. Trabajar con API REST.
29. Punto de venta (POS).
30. SQL en Odoo.

Cuantos más de estos puntos domine el consultor, más autonomía tendrá para resolver las necesidades del cliente sin depender de terceros.
