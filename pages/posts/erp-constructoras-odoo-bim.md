# ▷ ERP para Constructoras Odoo BIM

Odoo BIM 2.0 es una excelente solución para constructoras que necesiten un ERP para gestionar sus proyectos de construcción. Odoo es un ERP open source que permite gestionar la información de una empresa, desde la facturación, las compras y las ventas hasta los inventarios y la contabilidad.

## Presupuestos más fáciles
Con Odoo BIM 2.0, los presupuestos se hacen más fáciles, ya que permite importar los materiales desde Revit a Odoo y así tener un presupuesto más preciso. Además, la importación de tipo BoQ permite importar datos desde cualquier sistema que exporte un listado de materiales, como AutoCAD, Archicad, Tekla, etc.

## Alcance de Odoo BIM 2.0
1. Presupuestos de obra: permite calcular presupuestos por APU, mediciones, costos directos, costos indirectos, etc.

2. Certificaciones de avance: puedes certificar tu presupuesto por porcentaje de avance o por cantidad de metros cuadrados.

3. Registro de costes/gastos: cada vez que se realiza un gasto se registra en el sistema y se puede ver en el estado de pagos.

4. Análisis de coste/beneficio: se puede analizar el coste de cada obra o proyecto y ver si es rentable o no.

5. Método del valor ganado: se puede calcular el valor ganado de cada obra o proyecto.

6. Precios unitarios: se pueden cargar precios unitarios de obras anteriores y se pueden utilizar en las nuevas obras.

7. Solicitudes de materiales o servicios: se pueden solicitar materiales o servicios a proveedores desde el proyecto, con integración con Compras.

8. Estados de pago: controla los estados de pago de la obra.

9. Reportes varios: múltiples reportes para controlar la obra y los presupuestos.

10. Importaciones: importa BOQ, BC2, BC3, Excel, XML, etc.

11. Asistencias de obra: registro de asistencias de obra para llevar el control de los trabajadores.

12. Alquiler de equipos: controla el alquiler de equipos de obra tanto de proveedores como de la propia empresa.

13. Integración con Proyectos: exporta los proyectos a la aplicación Proyectos de Odoo y viceversa.

14. Integración con BC3: BC3 (formato FIEBDC-3) es un estándar de intercambio de bases de datos de precios y presupuestos en la construcción.

15. Integración con Excel: permite exportar e importar datos a Excel.

16. Listas de chequeo: permite crear listas de chequeo para controlar la obra.

17. Plan de calidad: permite crear un plan de calidad para la obra.

18. Documentación de obras: permite crear documentos de la obra asociados a cada proyecto.

19. Tickets de obra: permite crear tickets de obra para controlar los trabajos pendientes o realizados.

20. Gastos indirectos: permite crear gastos indirectos de la obra.

21. Contrato de obra: permite crear un contrato de obra.

22. ITE (índices técnico-económicos): permite crear índices técnico-económicos para la obra y así simplificar la creación de presupuestos.

23. Fórmulas polinómicas: permite crear fórmulas polinómicas para la creación de presupuestos.

24. Comparaciones de presupuestos: compara presupuestos de las obras para detectar diferencias.
